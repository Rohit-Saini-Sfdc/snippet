Firebase & GCS Free Tier Setup Guide

1
Create a Free Firebase Project

Go to the Firebase Console, click Add Project, and create a project (Google Analytics is optional). The project is automatically placed on the Spark Free Plan.

2
Enable Firebase Storage in a Free Tier Region

In the Firebase sidebar, click Build > Storage > Get Started. When prompted for a location, select a US region (e.g., us-central1 or us-east1) to qualify for Google Cloud Storage's 5 GB Always Free tier.

3
Enable Anonymous Authentication

In Firebase sidebar, click Build > Authentication > Sign-in method. Click Anonymous, switch the toggle to Enable, and click Save. This allows the extension to authenticate uploads cleanly without password prompts.

4
Configure Storage Security Rules

In Build > Storage > Rules, replace the rules with the following so links can be viewed in documents:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

Click Publish.

5
Register Web App & Copy Config

Go to Project Settings (gear icon) > General > Your apps, click the </> (Web) icon, name it "Snippet", and copy the firebaseConfig object into the quick paste box above.
